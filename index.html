Case study 01visual-financial-rag

Visual RAG Financial Analyst

A multimodal RAG system that uses computer vision and LLMs to analyze complex financial PDFs such as 10-K filings. YOLOv8 finds the tables, a vision-language model summarizes them, and every answer cites the exact table image it came from.

  • Python
  • LlamaIndex
  • YOLOv8
  • Gemini / OpenRouter
  • Streamlit
  • Docker
Code for Visual RAG Financial Analyst Live demo of Visual RAG Financial Analyst

Problem

Financial analysts spend hours cross-referencing the narrative text and the tables in 10-K filings. Traditional RAG struggles here: OCR loses table structure, charts and graphs get ignored, and context is lost between pages.

Approach

Look at the filing instead of just reading it. YOLOv8 detects the tables, GPT-4o or Gemini reads and summarizes each one, and LlamaIndex builds a fresh index for every uploaded document. A split-screen Streamlit app shows the original PDF next to the chat.

What was hard

Making answers trustworthy when the facts live in tables. Each answer carries a visual citation, the exact image of the table it used, so an analyst can check a number against the source. Large filings were slow to ingest, so table processing runs on concurrent vision threads.

Result

Ingestion runs 5× faster with concurrent vision threads, every answer cites its source table, and the app runs as a live Streamlit demo or a single Docker container.

Case study 02ForecastBench_expert_personas

ForecastBench Expert Personas

Team research on how expert personas change LLM forecasts on ForecastBench. I designed LLM judges that measure reasoning drift and ran the final evaluation on 9 models: topic-specific expert personas improved Brier scores for 7 of them.

  • Python
  • OpenAI API
  • Gemini API
  • LLM-as-judge
  • pandas
  • Plotly

Team project · fork of AndrewRWilliams/ForecastBench_expert_personas

Code for ForecastBench Expert Personas

Problem

Do expert personas actually make LLMs better forecasters? The team studied how expert personas behave on ForecastBench, scoring each model's forecasts with mean and relative Brier scores.

Approach

A series of experiments: persona system prompts, few-shot expert elicitation, top- versus bottom-ranked example forecasts, random versus topic-relevant examples, and all seven topic experts forecasting every topic, including ones outside their expertise.

What was hard

Judging the reasoning, not just the number. One experiment rates how similar two forecasts' reasoning is on a 1–5 rubric and tests whether an LLM judge can do that reliably; another checks human evaluations of forecasts against an LLM judge.

Result

In the final evaluation across 9 models, topic-specific expert personas improved (lowered) the average Brier score for 7 of them.

Case study 03open-rs

RL for Reasoning in Small LLMs

Code from the AAAI 2026 paper on improving reasoning in small LLMs with reinforcement learning (GRPO on DeepSeek-R1-Distill-Qwen-1.5B). For a reinforcement learning course project, my fork adapts GRPO training to a single-GPU SLURM job with DeepSpeed ZeRO-2.

  • Python

Fork of knoveleng/open-rs

Code for RL for Reasoning in Small LLMs

Problem

Can reinforcement learning make a small, 1.5B-parameter model reason better on a tight compute budget? The Open RS paper trains DeepSeek-R1-Distill-Qwen-1.5B with GRPO on 4 NVIDIA A40 GPUs within 24 hours.

Approach

The paper adapts GRPO and trains on a compact, curated set of math reasoning problems (7,000 samples). For my course project I re-ran that GRPO training on McGill's teaching cluster, with a new single-GPU DeepSpeed ZeRO-2 config and a SLURM job script.

What was hard

Fitting a recipe built for four 48 GB GPUs onto one GPU inside a 4-hour job. The job script offloads optimizer state to the CPU, turns off vLLM generation, and cuts GRPO to 2 generations per prompt, 1,024-token completions and a batch of 2 with 8-step gradient accumulation. Memory stayed the limit: one logged run was killed for running out of memory after 50 training steps.

Result

The paper reports AMC23 accuracy rising from 63% to 80% and 46.7% on AIME24, ahead of o1-preview, for about $42 of compute. My fork adds the single-GPU setup, plus the logs, checkpoint config and W&B completion tables from a 50-step run.
